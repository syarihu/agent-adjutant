# AGENTS.md

## Self-review

When reviewing a change to this repository — the self-review loop before a PR, a fix round, or a
review you are asked for — first do the review you would do anyway, every round: correctness, the
task's acceptance criteria, compatibility, tests, and anything else the change calls for.

Then check the diff against [docs/review-checklist.md](docs/review-checklist.md) as well. It adds
perspectives this repository has needed; it does not replace or narrow that review. Read its
"Do not raise" section before reporting.
