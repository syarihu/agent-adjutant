    code エディタが設定されていません

    IDE で開くには、config の ide キーに使うエディタを書いてください。

    config ファイル
    書ける値
    • パスを受け取るランチャーの名前: code / cursor / idea / studio など
    • {worktree} を含むコマンド: kitty @ launch --cwd {worktree} nvim など
    書く場所

    defaults に書くと全リポジトリに、repos の中のリポジトリのエントリに書くとそのリポジトリだけに効きます。

    "defaults": {
  "ide": "code"
}

    保存すると、次の更新でボードに反映されます。adj serve の再起動はいりません。
    warning hub を止める

    受信箱・タスク・gate の記録は残ります。次に起動すると、hubAutoResumeHours 以内なら同じ会話を再開します。
    warning worker のタブを閉じる

    この worktree の worker が動いているターミナルのタブを閉じます。worker は止まります。

    worktree は消えずに残ります。
